Security

Security-conscious deployment.

Security controls implemented during deployment and hardening.

✓
API Key Authentication

Protected API routes require an API key.

✓
Kubernetes Secrets

Sensitive configuration is supplied through Kubernetes Secrets.

✓
Internal Services

PostgreSQL and Redis are not exposed through public LoadBalancer services.

✓
ServiceAccount Token Reduction

Automatic ServiceAccount token mounting disabled on application workloads.

!
HTTPS & Network Policies

Deferred. Public API is not yet configured with HTTPS; NetworkPolicy enforcement remains a future hardening task.
